Connect to GitHub

To save a release, this page needs a GitHub access token. It stays in this browser, is only ever sent to api.github.com, and is forgotten when you close the tab. You can write and preview a release without connecting.

Repository settings

How do I get a token?
  1. Sign in to GitHub as the owner of the repository, then open Settings › Fine-grained tokens › Generate new token.
  2. Name it Release notes and choose an expiry of 30 days or less.
  3. Under Repository access choose Only select repositories and pick this repository.
  4. Under Repository permissions set Contents to Read and write, and Actions to Read-only (so this page can show whether the website build worked).
  5. Generate the token, copy it and paste it above. Treat it like a password: do not share it. You can delete it on GitHub at any time.

What changed

Add one item for each change (a feature, an enhancement, a fix). Pick what kind of change it is, give it a short description, then break it into sections: each section has its own explanation and screenshots, shown as Section 1, Section 2 and so on.

How to write the explanation

The buttons above each Explanation box add the formatting for you. You can also type it:

  • A blank line starts a new paragraph.
  • - text makes a bullet and 1. text a numbered list.
  • ## Heading adds a sub-heading.
  • > text makes a note box and !> text an important box.
  • ### Step title starts a numbered step. The text, notes and screenshots below it belong to that step.
  • [[image 2]] on its own line places this section's screenshot number 2 right there. Screenshots you do not place appear after the text of the same section.
  • Inside any text: **bold**, `code` and [label](https://example.com).
