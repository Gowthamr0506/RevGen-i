Overview

Version 2.42.0 delivers major enhancements with the introduction of two key modules: FTE Production Tracker and AR Chatbot (IVR Calls). These new capabilities are designed to automate productivity tracking, improve workforce performance visibility, and streamline IVR-based claim communication through seamless integration with the Pulse platform. Users will benefit from real-time productivity dashboards, configurable productivity targets, automated activity tracking, efficient IVR claim processing, and centralized access to IVR conversation notes.

By reducing manual effort and improving operational workflows, this release empowers users to monitor team productivity, manage claim follow-ups, and enhance overall operational efficiency across RevGen-i system.

New featureProductivity trackingFor Leads & ManagersFor FTE users

FTE Production Tracker Module

RevGen-i simplifies productivity monitoring by automatically tracking user activities across Demo, Claim Processing, Coding, and Payment Posting operations. Users can configure common and individual productivity targets, monitor real-time team and individual performance through interactive dashboards, and review historical productivity records with audit tracking, reducing manual effort and improving operational visibility.

  • Activity is tracked automatically for the processes assigned to each user.
  • Common targets apply to everyone, and individual targets can override them per user.
  • Dashboards show real-time performance for teams and for individual users.
  • Target history keeps day-wise records and audit logs, with Excel and CSV export.

Steps to use the FTE Production Tracker Module

  1. 1

    Enable the Productivity Toggle

    For All usersBeside the Navigation menu

    Upon logging into RevGen-i, users shall receive a Productivity Reminder pop-up whenever Productivity Tracking is disabled. Users should enable the Productivity Toggle available beside the Navigation menu to ensure their activities are considered for productivity calculations. The reminder continues to appear every five minutes until the toggle is enabled or the user selects Don’t Show Again.

    Note

    Productivity calculations of a user begin only after the Productivity Toggle is enabled.

  2. 2

    Assign processes to each user

    For Leads & ManagersHome›System Settings›Administrative Settings›Users

    Leads and Managers should navigate to Home → System Settings → Administrative Settings → Users and open the Add/Edit User window to assign applicable processes such as Demo, Claim Processing, Coding, and Payment Posting. The selected processes are used by the system to calculate productivity for each user.

    Note

    Leads and Managers should mandatorily assign all applicable processes to each user within the account. Productivity shall be calculated only for the assigned processes. Any activity performed under an unassigned process shall not be considered for productivity calculations.

  3. 3

    Set common productivity targets

    For Leads & ManagersHome›System Settings›Administrative Settings›Productivity Target

    Leads and Managers should now navigate to Home → System Settings → Administrative Settings → Productivity Target to configure common productivity targets for all users within the account. Leads and Managers can define Manual and Bulk targets for each process, which serve as the standard benchmarks for productivity calculations.

    Note

    The Productivity target setting window is accessible only by the users with privilege access.

  4. 4

    Review the target history

    For Same screen as Step 3Productivity Target›Productivity Target History

    The lower section of the interface displays the Productivity Target History table, allowing users to review day-wise target configurations, audit logs, and historical records. Users can also filter target history by month and export the displayed records in Excel or CSV format.

    Note

    The system maintains only one target record per day. Any updates made on the same day modify the existing record instead of creating a new one.

  5. 5

    Configure individual targets

    For Leads & ManagersProductivity Target›Set by User

    Using the Set by User toggle, Leads and Managers can configure Individual Productivity Targets for selected users. After searching and selecting a user, process-wise Manual and Bulk targets can be configured and activated using the Apply Individual Target checkbox overriding the Common Targets for that user.

  6. 6

    Individual target history

    For Same screen as Step 5Productivity Target›Set by User›Productivity Target History

    The Individual Target Configuration screen also includes a Productivity Target History table that maintains day-wise records of active Individual Targets. Users can review audit logs, filter historical records by month, and export the displayed information in Excel or CSV formats for reporting purposes.

  7. 7

    Monitor team performance

    For Leads & ManagersHome›Utilities›Productivity Dashboard

    Leads and Managers shall navigate to Home → Utilities → Productivity Dashboard to monitor team performance. The dashboard displays key productivity metrics, user-wise performance, process-wise productivity breakdowns, performance rating legends, search and filter options, and Excel export functionality for comprehensive productivity analysis.

    Note

    Users should have the privilege access to view the productivity dashboard. The productivity targets configured by the Leads and Managers, along with the corresponding claims achieved count for each individual user, shall be displayed.

  8. 8

    Review your own productivity

    For Normal FTE usersHome›Utilities›User Productivity Dashboard

    Normal FTE users shall navigate to Home → Utilities → User Productivity Dashboard to review their individual productivity performance. The dashboard provides My Contribution, productivity achievements against configured targets, process-wise performance details, historical filters, and Excel export functionality.

    Note

    The Normal FTE users should also have the privilege to access the User productivity dashboard.

AR Chatbot Module (IVR Calls)

RevGen-i enables users to seamlessly transfer eligible claims to the Pulse IVR platform for automated payer interactions while maintaining visibility of the claims within the system. The module validates required claim mappings, manages IVR call processing, and automatically retrieves summarized conversation notes into RevGen-i, improving claim follow-up efficiency while reducing manual effort.

  1. Move eligible claims from a claims bucket to the IVR Calls bucket, with remarks.
  2. Send the validated claims to the Pulse IVR platform.
  3. Leads and Managers trigger the IVR calls in Pulse.
  4. The summarized call notes return to the claim automatically, under Notes › IVR calls.
Note

The original claim stays in its source bucket while a copy is worked in IVR Calls.

Steps to use the AR Chatbot Module (IVR calls)

  1. 1

    Enable IVR Calls and map carriers

    For Managers & LeadsHome›System Settings›Administrative Settings›Accounts›Carrier Masters

    The Manager and Leads shall navigate to Home → System Settings → Administrative Settings → Accounts and enable the IVR Calls option. Next, navigate to Carrier Masters and map the appropriate IVR ID for each carrier. The mapped IVR IDs are used by the system while sending claims to the Pulse IVR platform.

    Note

    The IVR ID field in Carrier Masters shall remain read-only, and the IVR Calls bucket in the Submitted Claims screen shall not be visible until the IVR Calls option is enabled at the account masters.

  2. 2

    Move claims to IVR Calls

    For Users with privilege accessAny claims bucket›Move to IVR Calls

    Users should navigate to any claims bucket, select one or more eligible claims, and click Move to IVR Calls. Enter the required remarks and confirm the action to transfer the selected claims into the IVR Calls bucket for further processing.

    Note

    Only users with the privilege access shall be able to view the Move to IVR Calls button at the buckets. The original claim shall remain in the source bucket with same claim status, while a copy shall be created in the IVR Calls bucket. Claims already in IVR Calls bucket cannot be transferred again.

  3. 3

    Review the IVR Calls bucket

    For UsersSubmitted Claims›IVR Calls›Pending

    Open the IVR Calls bucket to review claims under the Pending status. Users can search claims by payer, select multiple claims, download the claims list, remove and send the claims back to the source bucket if required, or prepare eligible claims for IVR processing.

  4. 4

    Send for IVR Call

    For UsersIVR Calls›Send for IVR Call

    Select eligible claims through the checkbox and click Send for IVR Call. After entering the mandatory remarks, the system validates the required IVR ID, Ordering Physician NPI, and Ordering Facility Fed ID before transmitting eligible claims to the Pulse IVR platform.

    Now, the claims are successfully transmitted to the Pulse IVR Platform. Leads/Managers shall then log in to the Pulse IVR Platform using their credentials and manually trigger the claims for IVR calling.

    Note

    Only claims belonging to the same carrier can be sent in a single request, and the selection is limited to 20 patients (no limit on the number of claims) at a time. Claims with missing IVR ID, NPI, or Fed ID mappings remain in the IVR Calls bucket, while only eligible claims are sent to the Pulse IVR platform.

  5. 5

    Read the IVR notes on the claim

    For UsersClaim›Notes›IVR calls

    Once IVR call processing is completed, the summarized conversation notes received from the Pulse IVR platform are automatically attached to the corresponding claim under the Notes section as IVR calls. Users can review these notes to continue claim follow-up activities within RevGen-i.
